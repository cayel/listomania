# Exemples d'utilisation des filtres et du tri

## Scénario 1 : Rapport des listes Rock des années 90

**Objectif:** Créer un rapport de toutes mes listes de Rock des années 90, triées chronologiquement.

**Étapes:**
1. Ouvrir `/reports`
2. Cliquer sur "Filtres"
3. Sélectionner:
   - **Catégorie:** Rock
   - **Période:** Années 90 (ou 1990-1999)
   - **Trier par:** Période
   - **Ordre:** Croissant
4. Cliquer sur "Tout sélectionner"
5. Générer le rapport
6. Exporter en HTML

**Résultat:** Un document élégant avec vos listes Rock des années 90, ordonnées par période.

---

## Scénario 2 : Analyse statistique de ma collection complète

**Objectif:** Obtenir un fichier CSV de toutes mes listes pour analyser dans Excel.

**Étapes:**
1. Ouvrir `/reports`
2. Ne pas appliquer de filtres (garder "Toutes")
3. Trier par "Titre" (ordre alphabétique)
4. Cliquer sur "Tout sélectionner"
5. Générer le rapport
6. Exporter en CSV

**Résultat:** Un fichier CSV avec tous vos albums, prêt pour analyse dans Excel.

---

## Scénario 3 : Partager mes listes publiques récentes

**Objectif:** Créer un rapport des listes publiques modifiées récemment pour le partager.

**Étapes:**
1. Ouvrir `/reports`
2. Cliquer sur "Filtres"
3. Sélectionner:
   - **Visibilité:** Publiques
   - **Trier par:** Dernière modification
   - **Ordre:** Décroissant (plus récentes en premier)
4. Sélectionner les 5-10 premières listes
5. Générer le rapport
6. Exporter en HTML

**Résultat:** Un document moderne avec vos dernières listes publiques, prêt à partager.

---

## Scénario 4 : Inventaire par catégorie

**Objectif:** Créer des rapports séparés pour chaque catégorie musicale.

**Méthode:**
1. **Pour le Jazz:**
   - Filtre Catégorie: Jazz
   - Tri: Titre (alphabétique)
   - Tout sélectionner → Générer → Export HTML
   
2. **Pour le Rock:**
   - Réinitialiser les filtres
   - Filtre Catégorie: Rock
   - Tri: Titre (alphabétique)
   - Tout sélectionner → Générer → Export HTML
   
3. **Pour le Hip-Hop:**
   - Réinitialiser les filtres
   - Filtre Catégorie: Hip-Hop
   - Tri: Titre (alphabétique)
   - Tout sélectionner → Générer → Export HTML

**Résultat:** Un rapport HTML par catégorie, facile à archiver ou partager.

## Astuces

### Combiner plusieurs filtres

Vous pouvez combiner les filtres pour des requêtes très précises :

**Exemple:** Listes privées de Jazz des années 80, triées par nombre d'albums
- Visibilité: Privées
- Catégorie: Jazz
- Période: Années 80
- Tri: Nombre d'albums (décroissant)

### Utiliser les filtres comme prévisualisation

Les filtres affectent immédiatement la liste affichée. Utilisez-les pour :
- Vérifier le nombre de listes correspondant à vos critères
- Prévisualiser quelles listes seront incluses
- Ajuster vos critères avant de générer le rapport

### Badge de filtres actifs

Le badge numéroté sur le bouton "Filtres" vous rappelle combien de filtres sont actifs. Cela évite d'oublier qu'un filtre est appliqué.

### Réinitialiser entre deux rapports

Pour créer plusieurs rapports différents dans la même session, utilisez le bouton "Réinitialiser les filtres" pour repartir d'une base neutre.

---

## Cas d'usage avancés

### Rapport comparatif

Créez plusieurs rapports avec des filtres différents pour comparer :
- Listes publiques vs privées
- Évolution par période
- Distribution par catégorie

### Export multiple

Pour créer une archive complète :
1. Générer un rapport avec tous les critères
2. Exporter en HTML (pour présentation)
3. Exporter en CSV (pour analyse)
4. Exporter en TXT (pour backup)

Vous aurez ainsi trois formats différents du même rapport !
