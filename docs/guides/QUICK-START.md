# 🎯 Guide de démarrage rapide (5 minutes)

Bienvenue sur RankList ! Ce guide vous permet de démarrer rapidement et de créer votre première liste d'albums.

## ✨ En 5 étapes

### 1. Créer un compte (1 min)

```
1. Aller sur https://ranklist.app
2. Cliquer sur "S'inscrire"
3. Renseigner :
   - Email
   - Nom d'utilisateur
   - Mot de passe
4. Valider

✅ Vous êtes connecté !
```

### 2. Créer votre première liste (30 sec)

```
1. Cliquer sur "Mes Listes" dans le menu
2. Cliquer sur "Nouvelle Liste" (+)
3. Renseigner :
   - Titre : "Mes albums préférés"
   - Description : "Ma collection personnelle"
   - Période : 2024 (optionnel)
   - Visibilité : Privée
4. Cliquer sur "Créer"

✅ Liste créée !
```

### 3. Ajouter vos premiers albums (2 min)

```
1. Dans votre liste, cliquer sur "Ajouter un album"
2. Rechercher : "Pink Floyd Dark Side"
3. Sélectionner "The Dark Side of the Moon"
4. Répéter pour 2-3 autres albums :
   - "Led Zeppelin IV"
   - "Abbey Road - The Beatles"

✅ Albums ajoutés !
```

### 4. Organiser vos albums (1 min)

```
Mode Édition automatiquement actif

1. Glisser-déposer pour réorganiser
2. Les positions se mettent à jour automatiquement
3. Cliquer sur "Terminé" pour sauvegarder

✅ Liste organisée !
```

### 5. Partager votre liste (30 sec)

```
1. Cliquer sur "Partager"
2. Choisir :
   - "Liste publique" → Visible sur /explore
   - OU "Générer un lien" → Lien privé
3. Copier le lien
4. Partager !

✅ Liste partagée !
```

## 🎉 Félicitations !

Vous avez créé votre première liste RankList. Voici ce que vous pouvez faire ensuite :

### 📊 Générer un rapport

```
1. Menu → "Rapports"
2. Sélectionner votre liste
3. Cliquer sur "Générer le rapport"
4. Exporter en HTML/CSV/TXT
```

**Résultat** : Rapport professionnel avec grille de pochettes et statistiques

### 🔍 Explorer d'autres listes

```
1. Menu → "Explorer"
2. Parcourir les listes publiques
3. Filtrer par période ou rechercher
4. S'inspirer !
```

### 📈 Voir vos statistiques

```
1. Menu → "Statistiques"
2. Voir :
   - Albums par décennie
   - Top artistes
   - Albums favoris
```

### 🎵 Exporter en playlist

```
1. Ouvrir votre liste
2. Menu → "Exporter"
3. Choisir "Playlist M3U8"
4. Importer dans votre lecteur
```

## 💡 Astuces pour bien démarrer

### ✅ Organisation efficace

**Créer plusieurs listes thématiques** :
- "Rock classique"
- "Jazz moderne"
- "Découvertes 2024"
- "Albums à écouter"

**Utiliser les périodes** :
- Par année : "2024", "2023"
- Par décennie : "1980s", "1990s"
- Personnalisées : "Années 70-80"

**Ajouter des catégories** :
- Rock, Jazz, Hip-Hop, Electronic
- Facilite le filtrage

### ✅ Recherche optimale

**Recherche Discogs efficace** :
```
Bon : "Pink Floyd Dark Side"
Mieux : "Pink Floyd The Dark Side of the Moon"
Avec année : "Pink Floyd Dark Side 1973"
```

**Homonymes** :
- Soyez spécifique : "John Williams Star Wars"
- Vérifiez l'année dans les résultats

### ✅ Import rapide

**Pour > 10 albums** :

Option 1 - CSV :
```csv
Artiste,Titre,Année
Pink Floyd,The Dark Side of the Moon,1973
Led Zeppelin,Led Zeppelin IV,1971
The Beatles,Abbey Road,1969
```

Option 2 - JSON :
```json
[
  {
    "artist": "Pink Floyd",
    "title": "The Dark Side of the Moon",
    "year": 1973
  }
]
```

**Importer** :
1. Créer le fichier
2. Menu liste → "Importer"
3. Sélectionner le fichier
4. Valider

### ✅ Découvrir les fonctionnalités

**Modale détails Discogs** :
- Cliquer sur l'icône "i"
- Voir genres, styles, tracklist
- Lien vers Discogs
- Bouton Apple Music

**Export d'images** :
- Créer des mosaïques visuelles
- 3 styles : Grid, Collage, Compact
- Partager sur réseaux sociaux

**Rapports avancés** :
- Filtrer par visibilité, catégorie, période
- Statistiques Top 10 artistes et années
- Export professionnel HTML/CSV/TXT

## 🆘 Besoin d'aide ?

### Questions fréquentes

**Q: Comment ajouter des albums sans rechercher ?**
R: Utilisez l'import CSV avec ID Discogs

**Q: Puis-je modifier une liste publique ?**
R: Oui, seul le propriétaire peut modifier

**Q: Les pochettes ne s'affichent pas ?**
R: Vérifiez votre connexion, images chargées depuis Discogs

**Q: Comment supprimer un album ?**
R: Mode édition → Icône poubelle sur l'album

**Q: Mes statistiques sont vides ?**
R: Ajoutez des albums à vos listes
